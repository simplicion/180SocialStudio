# AI Director eval harness

Phase 0 of `docs/social-studio-mobile/AI_DIRECTOR_QUALITY_FIX_PLAN.md`. Runs the mobile Director
(`VideoAIDirectorService.directMobile`) on fixed inputs and writes a report you can compare across changes.

## Fixtures

`fixtures/*.json` are generated by `build-fixtures.ts` (edit the scripts there, then rebuild):

| id | what it tests |
|---|---|
| `talking-head-45s` | false start at the top, fillers, long pauses, CTA |
| `interview-two-speakers` | 16:9 two-shot with speaker labels → 9:16 following the speaker |
| `vlog-motion` | many shots, little speech: music, keep the visuals |
| `tutorial-screen` | screen recording, no face, a repeated explanation, OCR |
| `multi-clip` | three takes on the timeline, only the last one is good |

Each file holds `request` (the `MobileAIDirectRequest` the phone sends), `reference.mustDo` / `mustNotDo` (what a
skilled editor would do) and `reference.checks` (machine checks the report scores; report only for now).

```
npx tsx scripts/director-eval/build-fixtures.ts
```

## Run

```
# real model (keys from the env, or --env <file>)
npx tsx scripts/director-eval/run-director-eval.ts --provider claude --env apps/180-social-studio-backend/.env
npx tsx scripts/director-eval/run-director-eval.ts --provider openai --model <id>
# rule-based planner only (no LLM): the floor
npx tsx scripts/director-eval/run-director-eval.ts --provider none
# one fixture
npx tsx scripts/director-eval/run-director-eval.ts --provider claude --fixture multi-clip
```

Reports go to `scripts/director-eval/reports/<timestamp>-<provider>.{md,json}` (git-ignored): per fixture the
planner source and reason, provider/model, LLM calls, ops planned → applied (dropped, and by which filter), critic
score and issues, timeline stats, the checks, and the reference notes.

Stock B-roll and SFX lookups are not called (no network besides the LLM); music uses the built-in catalogue.
Each run costs one Director turn per fixture (up to 6 LLM calls each).
